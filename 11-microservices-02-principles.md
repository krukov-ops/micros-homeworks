
# Домашнее задание к занятию «Микросервисы: принципы»

Вам как DevOps-специалисту необходимо выдвинуть предложение по организации инфраструктуры для разработки и эксплуатации.

## Задача 1: API Gateway 

Предложите решение для обеспечения реализации API Gateway. Составьте сравнительную таблицу возможностей различных программных решений. На основе таблицы сделайте выбор решения.

Решение должно соответствовать следующим требованиям:

- обеспечение терминации HTTPS.

**Ответ:**

| Проверка аутентификационной информации | Да              | Да              || Да              | Да               |

**Выбор решения:**

Я выбираю NGINX(потому что это знаю хорошо 😁) в качестве API Gateway. Это связано с его высокой производительностью, надежностью и широкими возможностями настройки. NGINX поддерживает маршрутизацию запросов, проверку аутентификационной информации и терминацию HTTPS, что соответствует требованиям задачи. Кроме того, NGINX имеет обширную документацию и большое сообщество, что облегчает его использование и поддержку.


## Задача 2: Брокер сообщений

Составьте таблицу возможностей различных брокеров сообщений. На основе таблицы сделайте обоснованный выбор решения.

Решение должно соответствовать следующим требованиям:
- поддержка кластеризации для обеспечения надёжности,
- хранение сообщений на диске в процессе доставки,
- высокая скорость работы,
- поддержка различных форматов сообщений,
- разделение прав доступа к различным потокам сообщений,
- простота эксплуатации.

Обоснуйте свой выбор.

**Ответ:**
| Возможность                     | RabbitMQ        | Apache Kafka   | ActiveMQ       | Redis Streams |
|--------------------------------|-----------------|----------------|----------------|------------------|
| Поддержка кластеризации        | Да              | Да             | Да             | Да               |
| Хранение сообщений на диске    | Да              | Да             | Да             | Да               |
| Высокая скорость работы        | Средняя         | Высокая        | Средняя        | Высокая         |
| Поддержка различных форматов   | | Да              | Да             | Да             | Ограниченная    |
| Разделение прав доступа         | Да              | Да             | Да             | Ограниченная    |
| Простота эксплуатации            | Средняя         | Средняя        | Средняя        | Высокая         |  

**Выбор решения:**

Я выбираю Apache Kafka в качестве брокера сообщений. Это связано с его высокой скоростью работы, поддержкой кластеризации и возможностью хранения сообщений на диске. Kafka также поддерживает различные форматы сообщений и обеспечивает разделение прав доступа, что соответствует требованиям задачи. Кроме того, Kafka широко используется в индустрии и имеет активное сообщество, что облегчает его эксплуатацию и поддержку.
